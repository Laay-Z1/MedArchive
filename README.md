# МедАрхив

Стартовый каркас desktop-приложения на **Python + Tkinter + SQLite**.

## Требования
- Python 3.10 или новее
- Tkinter (обычно входит в стандартную поставку Python)

SQLite уже входит в стандартную библиотеку Python — отдельный сервер и установка СУБД не нужны.

## Запуск
1. Распакуйте проект.
2. Откройте папку проекта в VS Code или PyCharm.
3. Запустите:
   ```bash
   python main.py
   ```
4. При первом запуске автоматически создастся файл базы данных `data/medarchive.db`.

## Что есть в каркасе
- Регистрация и вход.
- Хеширование паролей средствами Python (`hashlib.pbkdf2_hmac`).
- Автоматическое создание SQLite-базы и таблиц.
- Главное окно с разделами: Главная, Медицинская карта, Лекарства, План лечения, Документы, Настройки.
- SQL-схема в `database/schema.sql`.
